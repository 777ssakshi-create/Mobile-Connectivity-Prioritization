# Dashboard

## `stakeholder_dashboard.html`

Enhanced executive/stakeholder prototype. Open the file in a modern browser. Plotly is loaded from a CDN, so an internet connection is required for charts to render.

The dashboard is designed around the management questions:

1. Where are the highest-priority markets?
2. How large is the benchmark gap and potential population impact?
3. How confident are we in the underlying data?
4. Does the ranking remain stable under alternative weights?
5. What should be investigated next?

## `legacy_dashboard_preview.html`

Earlier dashboard prototype kept to show design evolution and project provenance.

## Production Power BI recommendation

The repository does not include a `.pbix` binary. The HTML files are portfolio prototypes. See `../docs/dashboard_design.md` for the recommended three-page Power BI information architecture.
